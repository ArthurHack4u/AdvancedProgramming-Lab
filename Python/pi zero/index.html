Proyecto: Control de Servo Remoto con API

Esta aplicación explora un sistema de control distribuido usando dos Raspberry Pi. Un potenciómetro en una Pi (Cliente) controla un servomotor en otra Pi (Servidor) a través de una API web central, demostrando modularización, consumo de API y control de hardware en red.

Componentes del Proyecto

Todo lo que necesitas para construir y configurar el proyecto. Esta sección cubre tanto el hardware físico requerido como los pasos de instalación de software para ambas Raspberry Pi.

  • 🍓 2x Raspberry Pi (Zero / 3 / 4) con WiFi
  • ⚙️ 2x Servomotor (ej. SG90)
  • 🎛️ 2x Potenciómetro (ej. 10kΩ)
  • 🔋 2x Capacitor (ej. 1µF)
  • 🍞 Protoboards y cables Jumper
  1. Clona el repositorio en **ambas** Raspberry Pi: 
    git clone https://github.com/ArthurHack4u/AdvancedProgramming-Lab.git
  2. Navega a la carpeta del proyecto: 
    cd AdvancedProgramming-Lab/Python/pi\ zero/proyecto_sensor_servo/
  3. Instala las dependencias en **ambas** Pi: 
    pip install -r requirements.txt

    (Esto instalará Flask, requests y RPi.GPIO).

Modo de Uso

Esta es la guía paso a paso para ejecutar el sistema. Sigue las instrucciones para cada Pi. Necesitarás tener ambas Pi conectadas a la misma red local.

Paso 1: Configurar Pi 1 (Servidor + Actuador)

+

Esta Pi correrá la API y moverá el servo. Necesitarás 2 terminales.

  1. Obtén la IP de esta Pi (la necesitarás para la Pi 2): 
    hostname -I
  2. Terminal 1 (API): Inicia el servidor Flask. 
    python src/api/sensor_api.py
  3. Terminal 2 (Actuador):

    Abre `run_actuator_app.py` y asegura que `API_BASE_URL` sea `http://127.0.0.1:5000`.

    Ejecuta el script:

    python run_actuator_app.py

Paso 2: Configurar Pi 2 (Sensor)

+

Esta Pi solo leerá el potenciómetro y enviará los datos.

  1. Configura la IP: Abre `run_sensor_app.py` y edita `API_BASE_URL` para que apunte a la IP de la Pi 1 (del Paso 1).
  2. Terminal 1 (Sensor): Ejecuta el script. 
    python run_sensor_app.py
  3. Calibrar: Sigue las instrucciones en la terminal para calibrar el potenciómetro.

Paso 3: ¡Probar!

+

Una vez que la Pi 2 esté calibrada y corriendo, **mueve el potenciómetro en la Pi 2**.

Deberías ver el servomotor en la **Pi 1** moverse en tiempo real, replicando tu acción.
